# 7: Node.js Start

Each file is a separate example, run it with its number:

```
npm install
npm run 1   # http server on http://localhost:5000
npm run 2   # import from another file
npm run 3   # simple logger
npm run 4   # validator
npm run 5   # file system (appends to for-fs.txt and for-fs.json on every run)
npm run 6   # MySQL, needs a local server (root, password from DB_PASSWORD, default "password")
npm run 7   # fetch with http
npm run 8   # fetch with axios
```
