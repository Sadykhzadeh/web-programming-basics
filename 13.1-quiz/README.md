# 13.1: Quiz (suppliers and products)

## Run

1. Start MySQL and load the schema: `mysql -u root -p < db.sql`
2. Build and start:

```
npm install
npm run build
npm start
```

The app connects as `root` with the password from `DB_PASSWORD` (default
`12345678`). Open http://localhost:3000. Task description: `task.txt`.
